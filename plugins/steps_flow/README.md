# hegemony-steps-flow

Platform-orchestration steps: launch nested flow runs and send on-demand
notifications.

Handlers: `flow.run`, `flow.notify`.

Namespace prefix (= entry-point name): `flow.` — see the repo-level
`CONVENTIONS.md` for the naming rules.

# Container image licence policy for the step plugins
# ============================================================================
#
# Every image a Dockerfile under images/ builds on (FROM, COPY --from=<ref>),
# and every image a step pulls when its author sets none (a module-level
# DEFAULT_IMAGE or DEFAULT_IMAGES literal under plugins/), must be listed here.
# Enforced by scripts/check_image_licenses.py (task licenses:images, and
# tests/test_image_licenses.py in CI). The platform's licence process runs the
# same script against the release it pins.
#
# FORMAT -- the platform's (deploy/.images-allowed.txt), four pipe-separated
# fields:
#
#     repository | SPDX licence | tier | statement
#
# `repository` is the image reference with tag and digest removed.
#
# TIERS
#   first-party   An image this repository builds and pushes to ghcr.io. Its
#                 contents are Hegemony's redistribution obligation; see the
#                 image's THIRD-PARTY-NOTICES.md.
#   base-image    A layer inside an image built here. Conveyed when that image
#                 is published, so notice and source-offer duties attach.
#   step-default  An image a step pulls by default. The operator's Docker pulls
#                 it from its own registry into the sandbox; Hegemony conveys
#                 none of its bytes, and its licence binds whoever runs it.
#
# STATEMENT must say why the licence is acceptable for the tier, and for
# anything non-permissive, what would remove it.

Holds no Hegemony code: every component is third-party, named with its licence in images/ansible-runner/THIRD-PARTY-NOTICES.md, which the image carries at /usr/share/doc/hegemony/ with the written source offer.

# ============================================================================
# Operating-system package licence policy for the step plugin images
# ============================================================================
#
# Every package an `apt-get install` or `apk add` in images/*/Dockerfile
# installs must be listed here. Enforced by scripts/check_image_licenses.py.
#
# FORMAT -- as in images/.images-allowed.txt:
#
#     package | SPDX licence | tier | statement
#
# TIERS -- the tier, not the licence, decides whether copyleft reaches
# Hegemony's own code:
#
#   exec    A separate program the step's script starts, or data such a
#           program reads. Mere aggregation (GPL-2.0 s.2, GPL-3.0 s.5): strong
#           copyleft is acceptable and creates only notice and source-offer
#           duties, met by the image's THIRD-PARTY-NOTICES.md.
#   linked  Loaded into a Hegemony process. A licence that is not compatible
#           with AGPL-3.0-or-later is a hard failure here (FORBIDDEN_WHEN_LINKED
#           in scripts/check_image_licenses.py); GPL-3.0, LGPL and AGPL are
#           compatible.
#
# A package with the same name in the Debian (ansible-runner) and Alpine
# (opentofu-runner) images has one row covering both.

openssh-client | SSH-OpenSSH | exec | ssh for Ansible's ssh connection plugin, and git over SSH in both images. BSD-style; upstream states OpenSSH contains no GPL code.
sshpass | GPL-2.0-or-later | exec | Feeds passwords to ssh for playbooks that pin an ansible-core older than 2.19. Run by Ansible as a separate program. Conveyed in the published ansible-runner image, so it carries the GPL-2.0 s.3 source offer in images/ansible-runner/THIRD-PARTY-NOTICES.md.
git | GPL-2.0-only | exec | Clones roles and collections that a playbook's requirements.yml names, and OpenTofu module sources with git URLs. Always a separate program. Conveyed in the published ansible-runner and opentofu-runner images, so each carries the GPL-2.0 s.3 source offer in its THIRD-PARTY-NOTICES.md.
ca-certificates | MPL-2.0 AND GPL-2.0-or-later AND MIT | exec | The Mozilla CA bundle (MPL-2.0) that TLS clients read, plus the update script (Debian: GPL-2.0-or-later; Alpine: MIT). Data and a separate program; nothing links it.
